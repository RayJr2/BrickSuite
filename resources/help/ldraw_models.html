LDraw 3D Models

BrickSuite can read native geometry from an LDraw library installed on this computer. It does not download an LDraw library or send geometry to an online service.

Configure the library

Open Edit → Settings → 3D Models, choose the LDraw library root, and select Validate. A usable root contains parts and p folders and recognizable .dat files. Custom libraries are supported when they follow the same structure.

If a saved removable or network path is unavailable, BrickSuite preserves the setting and reports that the library is unavailable.

Open a model

Open Part Details and select 3D Model.... BrickSuite uses only exact stored LDraw external identities. It does not guess from the Rebrickable Part number. If more than one identity is stored, choose the intended model explicitly.

The information dialog reports the source, dimensions, triangle and edge counts, BFC information, and malformed or missing dependencies. Geometry loading runs in the background. Reload rereads the installed files.

Engineering OBJ export

Export OBJ... writes deterministic geometry in millimetres. The conversion is 1 LDraw unit = 0.4 mm. OBJ export is an engineering interchange feature; printability validation and repair are not performed.

Safety and limitations

BrickSuite rejects absolute, traversal, escaping symbolic-link, cyclic, ambiguous-case, malformed, and excessive references. M37.1 provides geometry inspection and OBJ export only; it does not provide an interactive 3D viewer, STL export, slicing, or remote Host geometry transport.
