LDraw 3D Models

BrickSuite can read native geometry from an LDraw library installed on this computer. It does not download an LDraw library or send geometry to an online service.

Configure the library

Open Edit → Settings → 3D Models, choose the LDraw library root, and select Validate. A usable root contains parts and p folders and recognizable .dat files. Custom libraries are supported when they follow the same structure.

If a saved removable or network path is unavailable, BrickSuite preserves the setting and reports that the library is unavailable.

Open a model

Open Part Details and select 3D Model.... BrickSuite uses only exact stored LDraw external identities. It does not guess from the Rebrickable Part number. If more than one identity is stored, choose the intended model explicitly.

3D Model... opens one persistent, non-modal viewer. You may close Part Details and continue using the viewer. Opening another Part reuses the same viewer window and replaces its current model.

Inspect the model

  • Left drag orbits around the Part.
  • Middle drag or Shift + Left drag pans.
  • Mouse wheel zooms.

Drag with the left mouse button to rotate freely through any orientation. Shift+left-drag or middle-drag pans, and the mouse wheel zooms. Use Fit to frame the complete Part without changing its orientation. Reset View returns to Isometric and fits the current scaled Part. Isometric, Front, Back, Left, Right, Top, and Bottom provide deterministic standard views. Perspective is the default; Orthographic is useful for engineering inspection.

Show Axes toggles the labeled corner XYZ orientation triad. X is red, Y is green, and Z is blue, using the same Z-up coordinate convention as engineering OBJ export. The triad follows camera rotation but is independent of Part pan, zoom, and Scale.

Model Color changes only geometry that inherits LDraw current color 16. Explicit and direct colors authored into the LDraw model remain unchanged. This is viewer presentation only and does not modify the Part, Inventory, or installed LDraw source. When opened from local My Inventory, the viewer initially uses that Inventory record's Color where available; generic Part Details uses Light Bluish Gray when available.

Render modes are Solid, Solid + Edges, and Wireframe. Solid + Edges shows LDraw hard edges and camera-dependent conditional edges. Wireframe also exposes triangle boundaries, including triangulation diagonals.

When a Part has multiple exact LDraw identities, select the candidate in the viewer. Candidate changes reset Scale and refit the new model while preserving Model Color and Show Axes. Reload Model rereads the selected source and dependencies while preserving the current camera, projection, render mode, Scale, Model Color, and Show Axes.

The compact information area reports source, dimensions, triangle and edge counts, BFC information, and malformed or missing dependencies.

Uniform Scale

Scale changes every dimension uniformly without modifying the installed LDraw source or BrickSuite's authoritative mesh. For example, 200% doubles every dimension. Values such as 99.5% or 100.5% affect every feature and may be used for dimensional experiments, but uniform scaling is not specialized LEGO fit or tolerance correction and does not guarantee compatibility. The Reset beside Scale returns only Scale to exactly 100%; it does not reset the camera.

Engineering OBJ export

Export OBJ... writes deterministic geometry in millimetres at the Scale currently shown in the viewer. At 100%, the conversion is 1 LDraw unit = 0.4 mm. The export header records the selected Scale and resulting dimensions.

Safety and limitations

BrickSuite rejects absolute, traversal, escaping symbolic-link, cyclic, ambiguous-case, malformed, and excessive references. Mesh repair / printability validation has not been performed. Review exported geometry in your slicer before printing. The viewer does not provide STL export, slicing, CAD editing, whole-model viewing, or remote Host geometry transport.
