Quick Start

This sequence establishes a useful workshop without requiring every advanced feature.

1. Create a Workspace

Use the Workspace tab to create or select the logical workshop. Settings can choose the Workspace selected at later startup.

2. Create Storage

Add the hierarchy from broad areas down to usable leaves. Set each location's Used For capability. Loose inventory requires an active Inventory or Both leaf; Collection items require an active Collection or Both leaf.

3. Configure providers when useful

Under Settings → APIs, add Rebrickable for API-backed composition, identity enrichment, and images. Add Brickset for Set enrichment and instructions. Catalog downloads and local entry do not require a continuous API connection.

4. Download reference files

Obtain Rebrickable parts.csv.zip, sets.csv.zip, and minifigs.csv.zip. Obtain part_relationships.csv or its ZIP for related Part identities. Each import accepts either the downloaded ZIP or extracted CSV.

Minifig Theme classification additionally uses one folder containing themes, sets, inventories, and inventory_minifigs CSV or ZIP files.

5. Populate catalogs

  1. Import Rebrickable Parts.
  2. Import Part Relationships after Parts.
  3. Import Rebrickable Sets.
  4. Import Rebrickable Minifigs and optionally Themes.

Wait for each completion report. Invalid or ambiguous ZIP input is rejected before catalog mutation.

6. Add or import inventory

In My Inventory choose Add Part..., or choose Import CSV for a previewed operation. Confirm Part/Color, Storage, Manufacturer, Condition, Ownership, and Quantity before committing.

7. Create a Build

Acquire Set or Minifig composition in Details and choose Create Build From Stock..., or create a MOC and enter/import requirements. Allocate, review Missing Parts, pull, and complete when required quantities are satisfied.

8. Add a Collection item

Use Add to Collection in Set or Minifig Details, or use an eligible completed Build's Actions menu. Review State, Condition, Completeness, Location, nickname, and notes.

9. Establish a backup

Create a manual backup with File → Backup Database.... Optionally configure automatic backup root, frequency, and retention under Settings.

BrickSuite reads supported provider data and external identities. It does not write catalog changes back to Rebrickable, Brickset, or BrickLink.
