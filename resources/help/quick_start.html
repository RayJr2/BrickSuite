Quick Start

This sequence establishes a useful workshop without requiring every advanced feature.

1. Create a Workspace

Use the Workspace tab to create or select the logical workshop. Settings can choose the Workspace selected at later startup.

2. Create Storage

Add the hierarchy from broad areas down to usable leaves. Set each location's Used For capability. Loose inventory requires an active Inventory or Both leaf; Collection items require an active Collection or Both leaf.

3. Configure providers when useful

Rebrickable API configuration is optional for bulk-file import. Add it under Settings → APIs when you want API-backed images, enrichment, or an explicit Get Parts from Rebrickable... refresh. Add Brickset for Set enrichment and instructions.

4. Download reference files

Download the official Rebrickable bulk files into one folder. BrickSuite recognizes all twelve supported datasets: Themes, Colors, Part Categories, Parts, Elements, Part Relationships, Sets, Minifigs, Inventories, Inventory Parts, Inventory Minifigs, and Inventory Sets. The downloaded .csv.zip files can be used directly; extraction is optional.

BrickSuite does not download these files automatically. Obtain current copies from Rebrickable whenever you want to initialize or update the local catalogs and composition.

5. Populate catalogs and composition

Choose Tools → Import Rebrickable Data Files..., select the download folder, review the discovered files and dependencies, then choose Import. This Global Rebrickable Importer is the normal setup and update path. Missing datasets may be omitted for a partial update; invalid or ambiguous input is identified before that dataset changes the database.

See Rebrickable Import for dataset and transaction details.

6. Add or import inventory

In My Inventory choose Add Part..., or choose Import CSV for a previewed operation. Confirm Part/Color, Storage, Manufacturer, Condition, Ownership, and Quantity before committing.

7. Create a Build

Open Set or Minifig Details. Locally imported composition appears automatically when available; choose Create Build From Stock... to snapshot its required pieces. Get Parts from Rebrickable... and Import Parts List... remain optional manual refresh or replacement paths. Alternatively, create a MOC and enter or import its requirements. Allocate, review Missing Parts, pull, and complete when required quantities are satisfied.

8. Add a Collection item

Use Add to Collection in Set or Minifig Details, or use an eligible completed Build's Actions menu. Review State, Condition, Completeness, Location, nickname, and notes.

9. Establish a backup

Create a manual backup with File → Backup Database.... Optionally configure automatic backup root, frequency, and retention under Settings.

BrickSuite reads supported provider data and external identities. It does not write catalog changes back to Rebrickable, Brickset, or BrickLink.
