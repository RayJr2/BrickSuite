My Inventory

My Inventory tracks loose physical pieces. A row identifies an exact Part and Color together with quantity, Storage, Manufacturer, Condition, and Ownership.

Search and filter

Enter a Part number or name in Search, optionally choose Category, Color, Storage, or Manufacturer, then choose Search. Filters combine. Choose the corresponding All... value to remove a filter.

If Add Part is opened while a specific Storage filter is active, that visible filter becomes the initial destination. Otherwise BrickSuite may reuse the most recent successful Add/import destination for this Workspace during the current application session. Closing BrickSuite clears this session memory.

Add a loose part

  1. Choose Add Part.... The dialog is non-modal, so it may remain open while you consult Parts Catalog or Part Reference.
  2. Enter a Part number, or send a selected part from Parts Catalog or Tools → Part Reference....
  3. Review the resolved Part and Category. For a BrickLink identifier, enable Try BrickLink ID to resolve through known cross-references.
  4. Select Color, an active Inventory-capable leaf Storage location, Manufacturer, Condition, Ownership, and Quantity.
  5. Add the entry and verify the resulting row.

Show all colors includes colors beyond those currently associated with the resolved Part.

Remember Part retains the resolved Part for the next entry. Keep Open controls whether the dialog stays open after a successful addition. The options are independent: one reuses identity and the other reuses the window.

If resolution fails: verify Parts Catalog was imported, try the exact Rebrickable number, or use Try BrickLink ID for a BrickLink number. Part Reference cannot add a part absent from the local catalog.

Add Part's Color list shows a square swatch of the stored catalog color beside its name. Swatches stay the same in Light and Dark themes. Colors with missing or invalid hex data remain selectable without a swatch.

Parts Catalog or Part Reference?

Use Parts Catalog for complete database search, categories, colors, external identities, relationships, and Details. Use Part Reference for visual family browsing and supported dimension grids. Both can send an exact local identity to Add Part.

Actions for an existing row

  • Details shows current inventory and Part information.
  • Edit changes supported descriptive attributes.
  • Move transfers a chosen quantity to another active Inventory-capable leaf and records both locations.
  • Correct Entry... adjusts a wrong stored count. Review the intended correction; do not use Move for a count correction.
  • Remove Entry... deliberately removes quantity and records the operation. It is not the same as Mark Lost.
  • Mark Lost... records physically missing pieces that may later be returned through Lost / Found.
  • View History shows additions, corrections, removals, moves, imports, Build activity, and Lost/Found events.

Import and receive inventory

Import CSV supports previewed Rebrickable Append, Replace, Subtract, and Compare Only. Select the operation and physical attributes, review projected quantities and errors, and only then apply. Compare Only never changes BrickSuite.

Supported BrickOwl order receiving also produces a preview with identity and color status. Committing valid rows is transactional and records history; cancelling makes no changes.

Identity and provenance

Manufacturer records who made the physical piece and is preserved through movement and Build workflows. Rebrickable and BrickLink identifiers describe catalog identity instead; they are not Manufacturer choices.

My Inventory is for loose pieces. Builds manage projects. My Collection records physical Sets, Minifigs, and MOCs.
