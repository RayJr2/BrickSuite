Start Here

If you are new to BrickSuite, begin with Getting Started for an introduction to the application.

New installation? Follow Quick Start for the step-by-step setup sequence: API configuration, catalog CSV imports, part relationships, Storage, and your first inventory import.

Using Help

  • F1 opens Help for the BrickSuite area you are currently using.
  • Back and Forward move through your Help navigation history.
  • Home returns to this page.
  • Help is non-modal, so you can leave it open while working in BrickSuite.
