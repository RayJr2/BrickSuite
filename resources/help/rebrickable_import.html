Rebrickable Import

BrickSuite can import an owned-parts CSV exported from Rebrickable into My Inventory. The import workflow lets you choose the destination Storage location and inventory attributes, preview exactly what the CSV will do, and then decide whether to apply the changes.

Selecting the CSV and Destination

From My Inventory, choose Import CSV. Browse to the Rebrickable owned-parts CSV you want to import.

Choose the Storage location where the imported loose parts physically belong, along with the Condition and Ownership values that should be assigned to the imported inventory.

In this example, the file rebrickable_parts_bricks-curved (1).csv is being imported as Used, Owned inventory into Cabinet Bricks / Round Curved Bricks.

Filename assistance: When a Rebrickable parts-list filename corresponds closely to an existing Storage location, BrickSuite can use that information to help select the destination. Always verify the Storage field before continuing; the selected location is where the imported inventory will be recorded.

Previewing the Import

Choosing Import from the first dialog opens an Import Preview before any inventory changes are committed. Use this preview to verify the CSV contents and the effect each row will have.

The preview summary shows the source filename, rows processed, valid rows, errors, and total piece quantity. The table then compares each CSV row with the current BrickSuite inventory.

The key columns are:

  • CSV Qty — quantity requested by the CSV.
  • Current Qty — quantity BrickSuite currently has for the matching inventory.
  • After Sync — quantity that will exist after the import is applied.
  • Status — the action represented by the row, such as New Inventory.
  • Error — validation information when a row cannot be processed normally.

In the example shown, BrickSuite processed 95 rows, all 95 were valid, there were 0 errors, and the CSV represents 169 total pieces.

Preview is the safety check. Review the rows, quantities, colors, and statuses before committing the import. Choose Cancel if the preview is not what you expected.

Completing the Import

When the preview is correct, choose Import. BrickSuite applies the previewed inventory changes and reports the completed result.

The example import completed successfully with 95 rows imported and 169 total pieces added.

If the preview contains invalid rows or an import encounters a genuine failure, review the reported error information rather than assuming all CSV rows were applied.

Verifying the Result in My Inventory

After the import, return to My Inventory and filter by the destination Storage location or search for one of the imported parts.

Here, filtering Storage to Shelf Top / Bricks Round & Curved shows the resulting inventory records, including multiple colors of 11477 — Brick Curved 2 x 1 No Studs [1/2 Bow]. The result contains 120 inventory records.

The inventory table now shows the imported part/color quantities alongside their physical Storage location, Condition, and Ownership values just like inventory entered manually.

Import and Inventory History

Rebrickable CSV imports are recorded in BrickSuite's inventory history. The history can include the import event, quantity, destination Storage location, and the source CSV filename. This makes it possible to trace how inventory entered the Workspace later.

Choose History from an inventory row's Actions menu to inspect those events. See My Inventory for more information about movement history.

Different Rebrickable CSV Files Have Different Purposes

BrickSuite uses several kinds of Rebrickable CSV data. They should not be confused:

parts.csv
  Updates Parts Catalog reference data.

sets.csv
  Updates Sets Catalog reference data.

Owned-parts / parts-list CSV
  Synchronizes your physical loose parts into My Inventory.

MOC CSV
  Supplies part requirements for a MOC Build.

The Parts and Sets Catalog imports maintain BrickSuite's local reference library. An owned-parts CSV represents physical inventory. A MOC CSV represents Build requirements rather than loose inventory.

Practical Import Guidance

  • Export a Rebrickable parts list that represents the physical group of parts you intend to store together.
  • Choose or verify the matching BrickSuite Storage location.
  • Set the appropriate Condition and Ownership values.
  • Read the preview before committing the import.
  • After importing, verify the result in My Inventory.
  • Use History later if you need to determine where an inventory quantity originated.
