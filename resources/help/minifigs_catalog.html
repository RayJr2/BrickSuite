Minifigs Catalog

The Minifigs Catalog is BrickSuite's local reference catalog for Minifig identification. It shows the Rebrickable Minifig number, name, declared part count, and available catalog image.

Populate or Refresh the Catalog

Choose Import Rebrickable Minifigs (CSV/ZIP), then select either an extracted minifigs.csv file or the ZIP downloaded from Rebrickable. BrickSuite can locate minifigs.csv inside a nested archive folder.

A complete import updates existing entries and adds new ones. Entries absent from a later complete Rebrickable snapshot are deactivated rather than deleted, preserving their stable BrickSuite identities.

Search and Browse

Search by Minifig name or Rebrickable number such as fig-005210. BrickSuite queries one page at a time; use Previous and Next to browse larger result sets. The page size follows the catalog result setting in Settings.

Minifig Details and Images

Use Actions... → Details to view the selected Minifig's catalog metadata and provider source. Images are downloaded asynchronously from the imported Rebrickable image URL and cached in BrickSuite's dedicated Minifig image cache.

Current scope: This catalog supports browsing and identification only. Constituent-part import, inventory Have/Need comparison, and building a Minifig from loose pieces are separate later workflow capabilities.
