Database Status & Integrity

Choose Tools → Database Status & Integrity... to view the current database file, schema version, size, catalog and inventory counts, and selected SQLite details.

Checks

Run Integrity Check asks SQLite to examine the complete database structure. Run Foreign Key Check looks for records whose required related records are missing. These read-only checks can take time on a large database; BrickSuite remains responsive while they run.

A Healthy result means the selected check found no problem. A reported problem is not automatically repaired. Review Application Log, preserve the database, and consider restoring a previously verified known-good backup.

Creating a new backup does not repair corruption and may preserve an existing problem. BrickSuite never automatically repairs database corruption from this dialog.

Actions

Open Database Folder opens the containing directory without opening or editing the SQLite file. The Backup and Restore buttons use the same verified workflows as the File menu.
