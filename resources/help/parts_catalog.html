Parts Catalog

The Parts Catalog is BrickSuite's searchable local reference database. It is distinct from Tools → Part Reference, which presents a curated visual guide to common families.

Import and refresh

Import Rebrickable Parts (CSV/ZIP) accepts parts.csv or its downloaded ZIP. Existing identities are updated rather than casually replaced. Import part_relationships.csv or its ZIP separately for alternate, mold, print, and related-part resolution.

Search and details

Search by Part number or name and narrow results by Category. Results remain paged rather than loading the complete catalog. Open Details for images, colors, material, relationships, external identifiers, and supported actions.

Add inventory

Use a row action or Part Details to send the exact catalog identity to Add Part. Selecting a catalog row avoids treating a display number as a new identity.

Provider identities

Rebrickable catalog IDs and learned BrickLink IDs are external identities associated with BrickSuite's stable Part record. They are not Manufacturer values and do not imply provider write access.

Use Parts Catalog for complete database searching and details. Use Part Reference for visual family browsing and dimension layouts.
