Sets Catalog

The Sets Catalog is BrickSuite's local reference catalog for LEGO Sets. It is populated from Rebrickable CSV data and can be searched without making a live API request for ordinary catalog browsing.

Populate or Refresh the Sets Catalog

Use the Import Rebrickable Sets (CSV/ZIP) button at the top of the Sets Catalog to populate or refresh the local catalog. Select either the downloaded ZIP archive directly or an extracted sets.csv file. BrickSuite also finds sets.csv in a nested archive folder.

For the full first-time setup sequence, see Quick Start.

Search the Catalog

Use the Search field to look for a Set by number or name. The Year filter can narrow the results to a specific year. Choose Search to apply the current criteria.

The results table shows the Set number, name, year, Theme ID, parts count, and an Actions... control for each row. Paging controls at the bottom of the catalog let you move through larger result sets.

Set Details

Open Actions... → Details for a Set to view its reference information and, when available, provider enrichment.

The upper portion of Set Details shows the local BrickSuite/Rebrickable reference information, including the Set number, name, year, Theme ID, parts count, and cached Set image when available.

Catalog Parts List

The Catalog Parts List stores reusable exact Part, Color, quantity, and spare information for the selected Set. Choose Get Parts from Rebrickable... to retrieve the complete list through the Rebrickable API. This API workflow includes the constituent pieces of Minifigs in the Set so the catalog composition represents the physical pieces needed to assemble it.

If API access is unavailable, choose Import Parts List... and select a Rebrickable parts list in CSV or ZIP form. ZIP files may contain the CSV in a nested folder. Both acquisition methods replace the same catalog composition and require confirmation when a parts list already exists.

Exact catalog identities: Every imported row must resolve to an existing BrickSuite Part and Rebrickable Color. If the input is malformed or an identity cannot be resolved, the existing catalog parts list remains unchanged.

Provider Enrichment

The Provider Enrichment section identifies the active provider used for additional Set information. When Brickset is connected and within the configured daily request threshold, BrickSuite can use Brickset enrichment.

Brickset enrichment can include:

  • Brickset Set ID
  • Theme and subtheme information
  • Minifigure count
  • Availability/category information
  • Brickset rating
  • Instruction count
  • Additional-image count
  • A provider link that opens the Set on Brickset

The Status line summarizes the provider state for the current Set and can also show session information such as how many Brickset getSets calls have been made.

Provider fallback: If Brickset is unavailable or BrickSuite has reached the configured Brickset daily request threshold, supported Set Details workflows can fall back to Rebrickable. BrickSuite identifies the active provider in the Set Details dialog so you can see which source supplied the information.

Provider configuration, connection testing, and the Brickset daily request threshold are described in Settings.

View Instructions

When Brickset enrichment is active and instruction information is available, Set Details shows a View Instructions button. Choose it to open the instruction list.

The Instructions dialog lists the available instruction files and identifies their type and description. Choose Open for the instruction you want to view.

BrickSuite does not host the instruction PDF itself. Instruction information is provided by Brickset and the PDF is hosted by LEGO. Choosing Open launches the selected PDF using your system's default web browser.

Why the button may not appear: View Instructions is shown only when the active provider supports instruction information and instructions are available for the Set. When BrickSuite is using a Rebrickable fallback, Brickset-only instruction controls are not shown.

Provider Links

The provider link near the bottom of Set Details opens the current Set on the active provider's website using the system's default browser. For Brickset enrichment, the link is labeled Open on Brickset.

Create a Build from a Set

After acquiring a catalog parts list, choose Create Build From Stock... in Set Details. Confirm the required-piece count, review the excluded spare-piece count, and enter the Build name. BrickSuite creates an ordinary Set Build and snapshots the required catalog pieces into its Build requirements. The new Build opens in the existing allocation, missing-parts, pulling, completion, and disassembly workflow.

The snapshot is independent of the catalog definition: refreshing the catalog parts list later does not alter an existing Build. You may create multiple Builds from the same catalog Set.

Complete Sets are separate: Add as Complete Set remains available from the Sets Catalog for tracking an intact physical Set. It does not use the catalog Build-from-Stock snapshot workflow.

For Build lifecycle and requirement management, see Builds. For allocation behavior, see Allocate Available.

Set Images

BrickSuite caches Set images locally when they are available. A cached image can be displayed without downloading it again each time Set Details is opened.

Add a physical Set to My Collection

From Set Details, choose Add to Collection to record a Set you already own. Review State, Condition, Completeness, optional Collection-capable Location, nickname, and notes independently. Complete means the user believes all required model pieces are present; optional catalog spare pieces are not included. This does not create a Build or consume loose inventory, and imported parts composition is not required. Add the same Set again for each physical copy you own.
