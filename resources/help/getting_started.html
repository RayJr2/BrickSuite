Getting Started

BrickSuite models your physical brick workshop as a digital twin. A typical first-use workflow is to create or select a Workspace, define the physical Storage hierarchy, and then add or import your loose inventory.

1. Workspace

A Workspace is the top-level container for your BrickSuite data. Select the Workspace you want to use before performing inventory or Build operations.

2. Storage

Create a hierarchy that reflects the way parts are physically organized. BrickSuite supports areas, cabinets, shelves, cases, drawers, bins, trays, compartments, and dividers. Inventory is assigned to active operational leaf locations rather than parent containers.

3. Populate My Inventory

You can add loose parts directly or import Rebrickable owned-parts CSV files. BrickSuite tracks part, color, quantity, condition, ownership type, and storage location.

4. Explore Catalogs

The Parts Catalog and Sets Catalog provide local Rebrickable reference data. Search and filters help locate parts and Sets without depending on a live API request for normal catalog browsing.

5. Build

Create Sets or MOCs as Builds. BrickSuite can compare requirements against loose inventory, allocate available pieces, identify shortages, pull parts, complete a Build, and later return parts to loose inventory when appropriate.

Keep Your Data Safe

Use File → Backup Database regularly. BrickSuite verifies backups and creates a safety backup before restoring another database.
