Getting Started

BrickSuite connects reference catalogs, loose inventory, Builds, and physical Collection items while preserving where pieces are stored and how they moved.

1. Workspace

Create or select the Workspace representing the workshop you want to manage.

2. Storage

Create the physical hierarchy you use. Active leaf locations may allow Inventory, Collection, or Both; parent locations organize the hierarchy but are not destinations.

3. Optional providers

Configure Rebrickable or Brickset under Settings → APIs when you want API-backed composition, images, enrichment, or instructions. Download-based catalog imports and local workflows do not require a continuous connection.

4. Reference catalogs

Populate Parts, Sets, and Minifigs from supported Rebrickable downloads. Catalogs describe reference identities; they do not assert ownership.

5. My Inventory

Add or import loose physical pieces with exact Part, Color, Manufacturer, condition, ownership, quantity, and Storage.

6. Builds

Create Set, Minifig, or MOC Builds. Requirements can be allocated, deliberately substituted, pulled, reconciled, completed, cancelled, or disassembled.

7. My Collection

Record each physical Set, Minifig, or MOC independently from loose inventory and Build history.

8. Protect the database

Create a manual backup and consider verified automatic backups. Use Tools → Database Status & Integrity for health checks and recovery guidance.

State, Condition, Completeness, and Collection Location describe different facts and may be changed independently.
